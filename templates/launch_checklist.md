# POD Launch Checklist

## Product files

- [ ] Final transparent PNG exists
- [ ] Mockup image exists
- [ ] Product title written
- [ ] Price selected
- [ ] Tags selected
- [ ] Description written
- [ ] Production partner selected
- [ ] Shipping profile selected

## Listing quality

- [ ] Main image is readable at thumbnail size
- [ ] Title includes buyer search terms
- [ ] First sentence says what the buyer gets
- [ ] Tags include product type, audience, style, and use case
- [ ] No trademarked phrases unless owned/licensed

## Publish sequence

1. Run `python pod_profit_scout.py sample_catalog.json`.
2. Fix any blocked products.
3. Publish one draft listing first.
4. Read back the live/draft listing ID.
5. Scale only after the test listing is verified.
